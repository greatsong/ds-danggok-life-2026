온혈과 냉혈 · 첫 분류 모델

🎯 오늘 만드는 것
  • 온혈·냉혈 분류기 초안 — 동물의 몸 정보를 보고 온혈인지 냉혈인지 맞히는 첫 모델

0. 왜 배우나

도감에서 처음 보는 동물을 만났다고 해 봅시다. 우리가 던지는 질문은 두 갈래입니다. "얼마나 오래 살까?"는 숫자를 묻고, "따뜻한 피일까 차가운 피일까?"는 둘 중 하나를 묻습니다. 지난 8차시 동안 우리는 앞의 질문처럼 숫자를 맞히는 회귀를 다뤘습니다. 오늘부터는 뒤의 질문처럼 정해진 칸 중 하나를 맞히는 분류를 시작합니다. 몸무게와 수명, 새끼를 기르는 방식만 보고 온혈인지 냉혈인지 맞히는 모델을 만듭니다. 오늘 첫 분류기를 돌리면 정확도라는 점수가 나옵니다. 꽤 높아 보이는 숫자가 나올 텐데, 그 첫인상을 어디까지 믿을지는 다음 차시에 다시 확인합니다.

1. 개념 이해 — 답의 모양이 문제를 가른다

숫자 하나냐, 칸 하나냐

"이 동물의 최대 수명은?"의 답은 27.3년처럼 어떤 값이든 나올 수 있는 연속된 숫자입니다. 반면 "이 동물은 온혈인가 냉혈인가?"의 답은 미리 정해진 두 칸 중 하나입니다. 이 차이가 두 문제를 가릅니다. 답이 연속된 숫자 하나로 나오면 회귀, 정해진 칸 중 하나로 나오면 분류입니다. 물음이 비슷해 보여도 답의 모양이 다르고, 답의 모양이 다르면 쓰는 도구와 점수를 매기는 방법까지 달라집니다. 그래서 새로운 예측 문제를 만나면 방법을 고르기 전에 답의 모양부터 확인합니다.

질문답의 모양회귀 / 분류
이 동물은 몇 년을 살까27.3년 같은 연속된 숫자회귀
이 동물은 온혈인가 냉혈인가두 칸 중 하나분류
이 종의 한 배 새끼 수는연속된 숫자회귀
이 종은 멸종위기인가위기·아님 두 칸 중 하나분류

정답은 주어지기도 하고, 사람이 만들기도 한다

회귀와 분류는 둘 다 정답이 붙은 데이터로 배우는 지도학습입니다. 5차시 수명 예측기는 종마다 실제 최대 수명이라는 정답이 붙은 데이터로 배웠습니다. 그런데 오늘은 사정이 조금 다릅니다. 이 데이터에는 온혈·냉혈이라고 적힌 열이 없습니다. 그래서 강(class) 열을 보고 포유류와 새를 온혈로, 나머지를 냉혈로 묶어 정답을 직접 만듭니다. 분류에서 이 정답을 레이블이라고 부릅니다. 어떤 기준으로 묶을지는 데이터가 정해 주지 않고 사람이 정합니다. 정답을 설계하는 이 판단이 모델의 성격을 이미 절반쯤 결정합니다. 학습시키는 코드 자체는 회귀 때 본 것과 같은 한 줄이라, 새로 겁먹을 개념은 아닙니다.

정확도 — 전체 중 맞힌 비율

분류기의 점수로 가장 먼저 만나는 것이 정확도입니다. 뜻은 단순합니다. 전체 예측 가운데 맞힌 비율. 100종을 예측해 83종을 맞히면 정확도 83%입니다. 오늘 첫 분류기는 약 83.5%가 나옵니다. 열에 여덟을 맞힌 셈이라 첫인상이 좋습니다. 그런데 이 첫인상에는 아직 비교 기준이 없습니다. 83.5%가 정말 높은 점수인지 판단하려면 무엇과 견줘야 하는지, 그리고 이 점수가 어떤 데이터 위에서 나온 것인지를 봐야 합니다. 오늘은 이 물음만 챙겨 두고, 다음 차시에 83.5%라는 숫자를 세 각도에서 다시 봅니다.

2. 숫자를 맞히던 회귀에서, 갈래를 맞히는 분류로

지난 8차시까지 회귀는 "이 동물은 몇 년을 살까"처럼 숫자를 맞혔습니다. 오늘부터 다루는 분류는 답이 숫자가 아닙니다. "이 동물은 온혈일까 냉혈일까"처럼 정해진 몇 개의 갈래 중 하나를 맞힙니다.

3. 정답 만들기 — 온혈은 누구인가

이 데이터에는 온혈·냉혈이라고 적힌 열이 따로 없습니다. 그래서 분류(class) 열로 정답을 직접 만듭니다. 포유류와 새는 스스로 체온을 유지하는 온혈, 나머지(어류·파충류·양서류)는 냉혈로 묶습니다.

  • 파일 = life_animals.csv · 동물 4,513종의 몸 정보(체중·수명·성숙 기간·임신 기간 등)
  • 회귀 때처럼 체중·수명이 빈 종을 먼저 빼면 3,188종이 남습니다. 오늘은 이 3,188종으로 모델을 만듭니다.

- 체중과 수명이 빈 종은 먼저 빼줘(3,188종 남아).
- 강이 포유류나 새면 온혈, 나머지는 냉혈으로 정답을 만들어줘.
- 체중·수명·성숙일수·임신일수·한 배 새끼 수를 보고 온혈인지 냉혈인지
  맞히는 랜덤 포레스트 분류기를 만들어줘. 빈칸은 중앙값으로 채워.
- 데이터를 다섯 조각으로 나눠 번갈아 시험하는 방식(교차검증)으로
  정확도를 재서 큰 숫자 카드로 보여줘.
- 필요한 라이브러리 목록(requirements.txt)도 같이 줘.

- 한국어 라벨, 초보자용 한국어 주석. main.py 전체 코드를 한 번에 줘.
  • AI가 아래 모습의 코드를 줌 (똑같지 않아도 OK)
② AI가 준 코드 (예시)
import streamlit as st
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_predict
from sklearn.metrics import accuracy_score

st.title("🧬 온혈? 냉혈? 첫 분류 모델")

# 데이터 불러오기 — 동물 4,513종의 몸 정보
url = "https://raw.githubusercontent.com/greatsong/modudata/main/data/life_animals.csv"
df = pd.read_csv(url)

# 체중·수명이 빈 종은 빼기(3,188종 남음) — 회귀 때 쓰던 그 손질
df = df.dropna(subset=["adult_weight_g", "max_longevity_yrs"])

# 정답 만들기: 포유류·새면 온혈(1), 나머지는 냉혈(0)
df["is_warm"] = df["class"].isin(["Mammalia", "Aves"]).astype(int)

# 입력(특징): 몸에 관한 다섯 가지 숫자
feats = ["adult_weight_g", "max_longevity_yrs",
         "female_maturity_days", "gestation_days", "litter_size"]
X = df[feats].fillna(df[feats].median())   # 남은 빈칸은 중앙값으로
y = df["is_warm"]

# 랜덤 포레스트 + 5겹 교차검증으로 정확도 재기
model = RandomForestClassifier(random_state=42)
pred = cross_val_predict(model, X, y, cv=5)
acc = accuracy_score(y, pred)
st.metric("정확도", f"{acc:.1%}")

  • 회귀의 model.fit()과 뿌리가 같은 도구 — 바뀐 건 "숫자" 대신 "갈래"를 맞힌다는 것뿐
  • 첫 정확도는 약 83.5% — 열에 여덟쯤은 맞힌 셈
  • 어느 갈래를 더 잘 맞히는지 보고 싶으면 대화로 개선 ↓

8. 확인 문제

지필 문항과 같은 유형입니다. 먼저 스스로 답을 적고 나서 펼쳐 보세요.

문제 1 — "이 종의 최대 수명 예측"과 "온혈·냉혈 판별" 중 분류는 어느 쪽인지 고르고, 판별 기준을 한 문장으로 서술하시오.

예시 답안 — 온혈·냉혈 판별이 분류다. 답이 연속된 숫자 하나로 나오면 회귀, 정해진 칸(온혈·냉혈) 중 하나로 나오면 분류이기 때문이다.

문제 2 — 전체 3,188종 중 온혈이 2,398종이다. 아무것도 배우지 않고 무조건 '온혈'로만 답하는 모델의 정확도를 구하시오.

예시 답안 — 2,398 ÷ 3,188 = 75.2%. 가장 흔한 답만 찍어도 나오는 이 값이 다음 차시에서 83.5%를 읽는 비교 기준(기준선)이 된다.

문제 3 — 이 데이터에는 온혈·냉혈 열이 없어 강(class) 열로 정답을 직접 만들었다. 이때 사람이 한 판단이 무엇인지 쓰고, 그 판단이 왜 중요한지 서술하시오.

예시 답안 — 포유류와 새를 온혈로, 어류·파충류·양서류를 냉혈로 묶는 기준을 사람이 정했다. 레이블을 어떻게 묶느냐에 따라 모델이 맞혀야 할 문제 자체와 갈래별 종 수의 균형이 달라지므로, 정답 설계는 데이터가 아니라 사람의 판단이며 결과 해석의 출발점이 된다.
